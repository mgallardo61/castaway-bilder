# castaway-bilder

Öffentliche Bilder für Castaway (private App, nur Eigengebrauch), damit jedes Gerät sie laden kann
(App, Chromecast, Android Auto, Google Home).

- `logos/<sender>.png`: Logos der Live-Sender, 1280×720, auf dunkler Kachel. Die Logos stammen aus
  [Zapp](https://github.com/mediathekview/zapp) (MIT License, Copyright (c) 2016 cemrich), erzeugt
  mit `.github/scripts/mediathek_logos.py` aus dem Castaway-Repo. Die Marken gehören den Sendern.

Nur Castaway schreibt hier; Dateinamen nicht ändern, die App verweist auf sie.
